Elementor MCP changelog

1.0.0 - 2026-08-30
* Completed the Elementor MCP brand, domain, metadata, namespace, and asset
  migration.
* Elementor is now the sole supported page-builder integration.

  prompts, documentation claims, and package references.
* Preserved WordPress core, Elementor, forms, SEO, custom fields, commerce,
  localization, diagnostics, and theme-settings integrations.
* Updated release verification and packaging for the reduced Elementor-only
  product surface.
