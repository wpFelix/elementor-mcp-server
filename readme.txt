abilities, OAuth, safety profiles, approvals, rollback, and prompts.

== Description ==

Elementor MCP is an open-source WordPress MCP server and Elementor MCP server
plugin for compatible AI clients. The free plugin provides transport,
authentication, safety
profiles, approvals, diagnostics, skills, design-library operations, and
WordPress content and developer abilities. It also includes the complete
Elementor Core workflow: page inspection and construction, element editing,
templates, global styles, and compatible Elementor 4 Atomic Elements, Classes,
and Variables. Elementor MCP Pro adds advanced specification reconstruction,
dynamic content, display conditions, popups, forms and submissions, custom
code, interactions, SVG upload, and premium agency workflows.

Elementor is the only page-builder surface. Forms, SEO, custom fields,
commerce, localization, diagnostics, and theme settings are separate
non-builder integrations and load only when their plugin is available.

== Safety ==

Every write is permission-checked and schema-validated on the server. Use
Production Safe for normal work. Preview site-wide or destructive changes
before applying them, and keep Developer Full Access for deliberate
maintenance only.

== Installation ==

1. Upload the plugin ZIP through Plugins > Add New > Upload Plugin.
2. Activate Elementor MCP.
3. Install and activate Elementor MCP Pro only for advanced Elementor and
   agency workflows.
4. Create an access token or configure OAuth.
5. Add the endpoint to your MCP client.
